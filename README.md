#  Estudos de Java

Repositório criado para acompanhar minha evolução no aprendizado de Java.

A proposta é estudar desde os fundamentos da linguagem até o desenvolvimento de aplicações mais completas com Programação Orientada a Objetos, banco de dados e Spring Boot.

##  Objetivo

Construir uma base sólida em programação e Java através de:

- teoria
- exercícios
- pequenos desafios
- projetos práticos
- boas práticas de programação
